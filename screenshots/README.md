# Aufnahmen zu Experiment 3

78 Vollseiten-Aufnahmen: 13 Seiten × 3 Breiten × zwei Farbschemata.

Benennung: `<nr>-<seite>--<breite>--<schema>.webp`

| Breite    | Viewport |
| --------- | -------- |
| `desktop` | 1440 px  |
| `tablet`  | 768 px   |
| `mobile`  | 380 px   |

Das Schema wurde über `prefers-color-scheme` emuliert (nicht über den
Themenschalter), `localStorage` war jeweils geleert — die Seiten zeigen also
das, was ein Besucher ohne eigene Wahl sieht. Bei jeder Aufnahme wurde
zusätzlich `scrollWidth` gegen `clientWidth` gemessen; keine Seite scrollt
waagerecht.

Die Bilder sind zur Ablage im Repository auf 1100px Breite skaliert und als
WebP (Qualität 75) gespeichert.
