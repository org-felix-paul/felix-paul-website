# 0008. GitHub repository made public

Status: accepted 2026-09-17

## Context

Earlier the gh repo was private. This did not allow readers to contirbute to blog posts.

## Options
Keep repo private and add another additional mechanism to allow others to contribute. 
    a) add another public repo with blog posts only
    b) add software on top that allows feedback
    c) implement feedback options yourself
    PRO: preview posts stay private
    CONS: additional overhead

Make repo public and benefit from github functionality and well establihed open source behaviour.
    PRO: uses established functionality without overhead
    CONS: preview posts are public

## Decision

Make repo public available.

## Consequences

Changed license so content can be used but I have to be referenced.
